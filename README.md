# 🐍 90 Days of Python

> 从 Python 基础开始，用 90 天建立真正能够解决实际问题的 Python 编程能力。

## 📖 项目介绍

这是我的 **90 天 Python 实战学习计划**。

我具备一定的 C 语言等编程基础，但 Python 的系统学习和实际编码能力仍然比较薄弱。因此，我希望通过 90 天持续学习和实践，逐渐掌握 Python，并将它真正应用到数据处理、办公自动化和实际项目中。

这个仓库用于记录整个学习过程，包括：

- 📚 每日学习内容
- 💻 自己编写的代码
- 🧩 每日练习题
- 📝 学习总结与复盘
- 🛠️ 阶段性实战项目
- 🐛 Debug 与踩坑记录

我的目标不是单纯“学完 Python 语法”，而是逐渐形成：

**分析需求 → 拆解问题 → 编写代码 → Debug → 测试 → 优化 → 完成实际任务**

的基本开发能力。

## ⏰ 每日学习方式

每天计划学习约 **1～1.5 小时**。

采用：

```text
知识学习
   ↓
自己编码
   ↓
练习题
   ↓
Debug
   ↓
复盘总结
```

### 1. 知识学习

学习当天的新知识点。

重点理解：

- 它是什么？
- 为什么需要它？
- 什么场景应该使用？
- 基本语法是什么？

不要求必须通过视频学习，优先采用文字、文档、示例和实际编码。

### 2. 自己编码

看懂示例并不等于真正掌握。

学习知识点之后，尽量关闭答案，从空白 `.py` 文件开始，根据需求自己实现程序。

### 3. 练习题

每天完成若干由易到难的练习。

遇到不会的问题：

```text
自己思考
   ↓
尝试编码
   ↓
查看报错
   ↓
自己 Debug
   ↓
仍然无法解决
   ↓
获取提示
   ↓
再次尝试
```

尽量避免一遇到问题就直接复制 AI 给出的完整代码。

### 4. 每日复盘

记录：

- 今天学习了什么？
- 哪些内容已经掌握？
- 哪些地方仍然不理解？
- 出现了什么 Bug？
- Bug 为什么出现？
- 最后是如何解决的？

## 🤖 AI 使用原则

在学习过程中会使用 ChatGPT、Codex 等 AI 工具辅助学习和开发。

但遵循一个原则：

> **AI 是编程助手，而不是代码替写工具。**

推荐流程：

```text
需求
 ↓
自己分析
 ↓
自己尝试
 ↓
遇到问题
 ↓
查看文档 / AI 提示
 ↓
自己修改
 ↓
运行测试
 ↓
AI Code Review
 ↓
理解并优化
```

避免：

```text
需求
 ↓
让 AI 生成全部代码
 ↓
复制
 ↓
运行成功
 ↓
结束
```

最终目标是能够判断 AI 生成代码的正确性，而不是完全依赖 AI。
